Para la sustentación: por qué no se toca su base de datos
Así sí: se le pide a su API

La pantalla de Compras llama a 04-inventario/api/registrar-entrada.php con la orden, el insumo y la cantidad. Inventario valida, guarda el movimiento en su base y devuelve el número del kárdex, que es el que se ve en la columna de arriba.

Así no: SQL sobre la base de Inventario

Ningún módulo abre la base de otro. Cada uno tiene la suya (sicaf_compras, sicaf_inventario) y solo su propio bd/conexion.php la abre.
